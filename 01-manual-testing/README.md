# 🧪 Proyecto 01 — Manual Testing

## Objetivo

Realizar pruebas funcionales sobre una aplicación web, identificando posibles defectos y documentando los resultados de las pruebas.

## Alcance

Se probarán principalmente:

- Registro de usuario
- Inicio de sesión
- Navegación
- Productos
- Carrito de compras
- Proceso de compra

## Tipos de pruebas

- Functional Testing
- Positive Testing
- Negative Testing
- Regression Testing
- UI Testing

## Documentación

- Test Plan
- Test Cases
- Bug Reports
- Test Execution Results
- Evidencias

## Herramientas

- Jira
- GitHub
- Navegador web
