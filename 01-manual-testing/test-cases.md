# Test Cases

## TC-001 — Inicio de sesión con credenciales válidas

**Precondiciones:**
- El usuario está registrado.
- La página de inicio de sesión está disponible.

**Datos de prueba:**
- Email: usuario@test.com
- Contraseña: Password123

**Pasos:**
1. Abrir la página de inicio de sesión.
2. Introducir un email válido.
3. Introducir una contraseña válida.
4. Pulsar el botón "Iniciar sesión".

**Resultado esperado:**
El sistema autentica al usuario correctamente y lo redirige a la página principal.

**Resultado obtenido:**
Pendiente de ejecución.

**Estado:**
Not Run
