# TC-003 — Inicio de sesión sin contraseña

**Precondiciones:**
- El usuario está registrado.
- La página de inicio de sesión está disponible.

**Datos de prueba:**
- Email: usuario@test.com
- Contraseña: dejar vacío

**Pasos:**
1. Abrir la página de inicio de sesión.
2. Introducir un email válido.
3. Dejar el campo contraseña vacío.
4. Pulsar "Iniciar sesión".

**Resultado esperado:**
El sistema debe impedir el inicio de sesión y mostrar un mensaje indicando que la contraseña es obligatoria.

**Resultado obtenido:**
Pendiente de ejecución.

**Estado:**
Not Run
