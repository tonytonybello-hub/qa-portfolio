# TC-002 — Inicio de sesión con contraseña incorrecta

**Precondiciones:**
- El usuario está registrado.
- La página de inicio de sesión está disponible.

**Datos de prueba:**
- Email: usuario@test.com
- Contraseña: contraseña_incorrecta

**Pasos:**
1. Abrir la página de inicio de sesión.
2. Introducir un email registrado.
3. Introducir una contraseña incorrecta.
4. Pulsar "Iniciar sesión".

**Resultado esperado:**
El sistema debe rechazar el inicio de sesión y mostrar un mensaje indicando que las credenciales son incorrectas.

**Resultado obtenido:**
Pendiente de ejecución.

**Estado:**
Not Run
